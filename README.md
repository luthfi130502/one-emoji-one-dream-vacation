Entry for the make.fun bounty
[One Emoji, One Dream Vacation](https://make.fun/bounty/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35).

The whole entry is a single emoji — 🗻 — Mount Fuji, the dream vacation
as one postcard image: a specific place, instantly readable anywhere,
no words needed.

## How to run

```sh
python3 main.py
```

This writes the emoji to `/output/entry.txt` (UTF-8, exactly one
character). The script asserts the gate before writing: 1–8 characters,
not only whitespace, exactly one emoji.
